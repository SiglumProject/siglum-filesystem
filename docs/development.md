# Filesystem development

Paths in this map are relative to the repository root.

## Repository Map

| Path | Purpose |
|------|---------|
| `src/index.ts` | Public package exports |
| `src/FileSystemService.ts` | Mounts, backend selection, events, and file operations |
| `src/OPFSBackend.ts` | OPFS storage and worker sync access handles |
| `src/IndexedDBBackend.ts` | IndexedDB storage, imported through its package subpath |
| `src/constants.ts` | Storage identifiers and backend preference key |
| `src/types.ts`, `src/globals.d.ts` | Shared interfaces and browser API declarations |
| `src/compression.ts` | Native stream compression and synchronous fflate utilities |
| `tests/` | Bun tests, fake IndexedDB setup, and storage recovery regressions |
| `package.json`, `tsconfig.json` | Published entry points, commands, and TypeScript build settings |
| `dist/` | JavaScript and declarations generated by `bun run build` |

For local development, run `bun install`, `bun run build`, and `bun test`.
Contributor guidance is in [AGENTS.md](../AGENTS.md).
